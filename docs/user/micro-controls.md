# Creator Micro controls

Select this T3 installation in Micro Manager's desktop app setting. On your T3
layer, enable the dial and joystick and assign any spare buttons, then save and
apply that layer. Ordinary shortcuts stay configured in Work Louder Input.

Session keys open their assigned conversation and bring T3 forward. The dial,
joystick, and action buttons work while the selected T3 desktop app is frontmost.

While reading a conversation, turn the dial to scroll and press it to jump to the
latest message. Move the joystick down to focus the composer. The dial then moves
between available settings, including project, workspace, branch, model,
reasoning, and permissions. Press to open a setting, turn to browse its options,
and press again to confirm. Moving the joystick down cancels an unconfirmed
choice and returns the dial to scrolling.

Spare buttons can create a thread or project, focus the composer, jump to the
latest message, settle the current thread, toggle the terminal, or open the
command palette. Settling uses the same behavior as T3's regular settle action,
including any [project settlement commands](project-settings.md#clean-up-resources-when-settling-a-worktree)
you have enabled.
